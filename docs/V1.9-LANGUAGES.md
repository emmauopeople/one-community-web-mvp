# v1.9 — English and French

The public web, provider screens, admin portal and Expo app now include an EN/FR selector. English is the initial fallback; the choice is saved locally (browser storage / native AsyncStorage). Translation catalogs are bundled, so switching does not require an internet translation service.

System labels, categories, help, forms, moderation and common errors are translated. Provider names, listing titles/descriptions, reviews and entered messages remain in their original language. Switching does not reset drafts or change the category/status values submitted to APIs.

Search recognizes common French service words, including plombier, menuisier and électricien, alongside their English equivalents. This is category synonym expansion, not automatic translation of listing content.

Migration 007 adds the selected language to new analytics events. Historical events remain unknown (NULL). Visitor GPS remains excluded from analytics. Existing migrations are unchanged and the same migration can be applied on OVH.

## Validation

30 foundation/integration tests, 18 existing package tests and 8 mobile tests pass. Web/admin production builds and Android JavaScript export pass. Browser interaction checks cover French search/category values, help, provider drafts, review errors and admin status filters. A React Native Web harness checks the mobile discovery and registration screens; physical Expo Go testing remains required.

## Local acceptance

1. Rebuild Docker services and run migrations with the supplied test script; install mobile dependencies and restart Expo with its cache cleared.
2. Switch EN/FR on public web, provider and admin pages; reload and confirm the saved language.
3. On Expo Go, switch language, close/reopen the app and confirm persistence.
4. Search for plombier and plumber; compare matching categories. Test location consent and distance in both languages.
5. Switch language with a partially filled registration/review/skill form and confirm entered text remains intact.
6. Submit a review, then approve, inactivate and soft-delete from the French admin interface. Only approved reviews may appear publicly.

OVH image storage configuration and low-bandwidth acceptance follow this language update. No storage credentials belong in source control. Transactional email templates retain their existing behavior; this update covers the application interfaces.
